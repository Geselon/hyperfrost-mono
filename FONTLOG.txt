Hyperfrost Mono Project Font Log
==========================

This file provides detailed information on the Hyperfrost Mono font software family, including all active variants, project history, and modifications.

Log of Changes
--------------

*** Hyperfrost Mono ***
2026-08-31 (Geselon) Version 1.000
- Initial fork of Atkinson Hyperlegible Next Mono.
- Increased character width density to match JetBrains Mono proportions.
- Realigned and enlarged the vertical axis of the asterisk (*) symbol.
- Renamed OpenType name tables to satisfy OFL naming restrictions.
- Changed to more exaggerated, elegant curly braces {} for better distinction against square brackets [] and parentheses ().
- Emboldened the following punctuation marks for better visibility: double quote ("), single quote ('), backtick (`), period (.), colon (:), and semicolon (;).
- Enlarged all characters for easier readability and legibility when using smaller font sizes.
