Slim Clarity Mono Font Log
==========================

This file provides detailed information on the Slim Clarity Mono font software.
This information includes a description of the project, modifications made, and attribution acknowledgments.

Log of Changes
--------------
2026-08-27 (GesElon) Slim Clarity Mono Version 1.000
- Forked from Atkinson Hyperlegible Next Mono.
- Increased character width density to match proportions of JetBrains Mono and Fira Code.
- Realigned the vertical axis of and enlarged the asterisk (*) symbol.
- Renamed OpenType name tables to satisfy OFL naming restrictions.
